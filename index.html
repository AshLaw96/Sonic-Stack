How to Play

Keyboard

  • ← → Move left/right
  • ↓ Soft drop
  • ↑ Hard drop (instant)
  • Space Rotate piece
  • H / Shift Hold piece
  • P Pause / Play game

Touch Controls

  • Use on-screen buttons to move.
  • Down speeds up the piece.
  • Double arrow down for instant drop
  • Rotate twists the current piece.
  • Hand icon holds current piece.
